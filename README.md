Tic-Tac-Toe 

A simple but fun game to play

So we know it is a game played between two players. The aim of the game is to get three of your marks in a line. Although it is a simple game to understand, it does require some strategy so you need to plan ahead.

This was made as a practice project so I can improve my frontend skills and see how I can make this simple game into something that will be easy to use.

How to Play

If you have played Tic-Tac-Toe before then you will know how to play.

The game consists of a 3x3 grid. Player one will be using X and player two will be using O. Players will take turns to place their mark onto an empty box. The aim of the game is to get three in a row, either horizontal, vertical or diagonal. The first person to get three in a row wins. However, if all nine boxes have been filled with no one having three in a row then it is a draw.

Plan your moves and block your opponent to see who wins

Modern Mode


Modern Mode takes the traditional game of Tic-Tac-Toe and makes it more dynamic. Each player can only have 3 pieces on the board. With each move, the game can quickly change. You’ll need to think carefully about which piece will be removed next.

How To Play

1. 3 Pieces: You can have up to 3 pieces on the board.

2. Oldest Piece Gets Removed: On your 4th piece, your oldest will be removed.

3. Repeat: On your 5th you will remove your 2nd piece, on your 6th you will remove your 3rd piece.

4. Win: 3 of your pieces in a row (horizontally, vertically, diagonally).

Why Is It Different?

In a traditional game of Tic-Tac-Toe you can play purely off the current board. However, with Modern Mode, you will need to plan ahead. Because the pieces are being removed, your pieces could be removed on your next turn meaning your opponent can take advantage.

Plan Ahead: Know which piece will be removed next.

Plan Moves: Try to set up opportunities for yourself but also protect yourself.

Stay Alert: The board is continuously changing so you could be caught out if you’re not careful.

Challenge

The fun part of this game is trying to balance your next move with what will happen next. You need to try and create lines to win the game, whilst blocking your opponent.

It’s a fun variation of Tic-Tac-Toe. It requires some extra strategy and means the board is always changing. You can really outsmart your opponent.

How to Run

To run this game locally you will need:

Node.js (https://nodejs.org/)

Git (if you wish to clone my repo)

To run locally:

Clone the repo:

git clone YOUR_GITHUB_REPO_URL

Navigate to the project directory:

cd YOUR_PROJECT_NAME

Install dependencies:

npm install

Start the dev server:

npm run dev

Then navigate to the local URL shown in your terminal.

Replace YOUR_GITHUB_REPO_URL and YOUR_PROJECT_NAME with your actual repo URL and project name.
